January 2017 to June 2019  
Eolementhe is a video manipulation and transfer solution.    
Following the LCA, several actions were identified :  
* Optimize the user journey to avoid repetitive actions
* Modify the encoding format
* Automatically check and optimize user-uploaded images
* Reduce the size of uploaded files
* Reduce file upload times
* Adjust data center resources by migrating to the cloud
* Select a hosting provider that powers its data center with renewable energy
* Raise user awareness regarding environmentally friendly practices
