2023  
Using available tools and best practices (mostly RGESN), the website was designed to have as little environmental impacts as possible.  
   
## Key figures
In average, for selected pages :  
* FCP : -50%
* LCP : -33%
* Speed Index : -66%
* Page weight : -15%

## Beyond the numbers
This is one of the (too few) cases where performance metrics were evaluated in addition to sustainability metrics.   
As stated in the [definition page of this website](https://bc4ds.laudevsat.fr/business-case/), the impact of web performance is more comprehensively documented.
