Some best practices were implemented : 
* Progressive loading
* "Just-in-time" networking
* Aggressive caching
* "Offline-first" mobile experience
   
## Key figures
* Load speeds improvement : 133x
* Year-over-year engagement on web-based map experience : +200%
* Reduction on data loads : 99.25%
* Daily savings on the server side : $13.5

## Beyond the numbers
* Dramatically reduced the number of API calls needed to use web and mobile products
* Higher engagement with map products led to the discovery of more use cases
* The offline-first mobile app enabled more scenarios where users have no coverage
